With the help of [ChatGPT](https://chatgpt.com) I resolved the problem with the FH7 content and it now appears properly.

*Just in case you're interested*

It turned out that there were two problems:
- The names of some of the FH7 files started with an underscore; and,
- the FH7 files used old-style internal alinks which failed the HTML5 proof-reader.

The former was easily fixed with a Python script offered by ChatGPT that renamed the problem files and adjusted the internal alinks. The site now generated correctly, but still failed the step in the GitHub Action that proof-read the generated site:

```
- name: Test site
        run: |
          bundle exec htmlproofer _site \
            \-\-disable-external \
            \-\-ignore-urls "/^http:\/\/127.0.0.1/,/^http:\/\/0.0.0.0/,/^http:\/\/localhost/"
```
This failed because the alinks in the FH7-generated content were badly formed (as seen from the HTML5 spec).

A example was:
```
<div class="fhsection fhsubdata">
<dl class="FhDefList"><div class="fhsecdata">
<dt><a name="src-4">4.</a></dt>
<dd><p><span class="i">1901 Census Entry for 41 Court Road, Barry, Glamorganshire, Wales</span>, (RG13-4993-6-4). Custom Id: CENS-GB1901-WAL-GLAM-41_Court_Road; Cit. Date: 31 March 1901. General Register Office, Kew.</p></dd>
</div>
```
The string `<a name="src-4">4.</a>` is badly formed as per HTML5. It should read something like: `<span id="src-4">4.</span>`

ChatGPT worked this out. The final python script is
```
#!/usr/bin/env python3

import re
from pathlib import Path

# Change this to the directory containing the Family Historian output.
ROOT = Path("genealogy")

# Find all files whose names start with an underscore.
files = [
    path for path in ROOT.rglob("*")
    if path.is_file() and path.name.startswith("_")
]

# Build a mapping of old filenames to new filenames.
renames = {}

for path in files:
    new_name = "fh-" + path.name[1:]
    new_path = path.with_name(new_name)

    if new_path.exists():
        print(f"Skipping rename: {path} -> {new_path} (destination exists)")
        continue

    renames[path.name] = new_name

# Rename the files.
for path in files:
    if path.name not in renames:
        continue

    new_path = path.with_name(renames[path.name])
    print(f"Renaming: {path} -> {new_path}")
    path.rename(new_path)

# Update references in HTML files.
for path in ROOT.rglob("*.html"):
    content = path.read_text(encoding="utf-8")

    original = content

    for old_name, new_name in renames.items():
        content = content.replace(old_name, new_name)

    # Convert legacy named anchors to HTML5 span elements.
    content = re.sub(
        r'<a\s+(?:name|id)=(["\'])(.*?)\1>(.*?)</a>',
        r'<span id=\1\2\1>\3</span>',
        content,
        flags=re.IGNORECASE
    )

    if content != original:
        print(f"Updating references in: {path}")
        path.write_text(content, encoding="utf-8")

print("Family Historian HTML processing complete.")
```
