I use [Family Historian](https://www.family-historian.co.uk) to manage my content.
It has a function to _publish_ a web site with content chosen by me.

Unfortunately, it prefixes some of the filenames with an underscore '_'.
The site is generated using [jekyll](https://jekyllrb.com) and it ignores any files or directory that starts with an underscore.

That means, that the site is broken by the build process.
I'll have to develop a _pre-processing_ step for the [GitHub](https://github.com) action that builds the site. The new step will have to rename the files and adjust all the references in the generated html.
